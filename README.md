# Project Medica

一个正在开发中的 Minecraft Java 版 Fabric 草药、外伤与急救模组。

薄荷基础玩法已阶段性完成，目前正在开发 **植物纤维 → 简易麻绳 → 简易绷带** 的早期急救材料链。当前版本已包含流血和基础急救，但生存模式下的治疗用品制作链仍未完成。

## 当前内容

### 外伤与急救

- 玩家实际受到蜘蛛（含洞穴蜘蛛）或甜浆果丛伤害后，会获得约 60 秒的流血；已有流血时不重置持续时间。
- 流血每累计 5 秒造成 1 点生命伤害（半颗心），可以致死；持续时间结束后自然止血。
- **普通绷带**：流血时持绷带按住右键约 3 秒，完成后消耗一个并移除流血，不直接回血。提前松开或切换物品会取消，不消耗绷带。
- **空手按压**：双手为空，潜行并按住右键约 8 秒，获得约 15 秒的“空窗期”。按压期间可以移动；取消后需要重新按住右键并重新计时。
- **空窗期**暂停流血伤害计时及流血剩余时间的流逝，不直接清除流血；结束后仍有流血则继续。首次获得空窗期解锁“迫在眉睫”。

以上时间按正常游戏速度计算。普通绷带的使用功能已实现，但目前没有合成配方，可在测试世界中用指令获取：

```mcfunction
/give @s project-medica:bandage
```

### 植物纤维与简易麻绳

- **植物纤维**：生存模式空手破坏矮草获得 1 个；破坏高草丛上半部或下半部，整株合计获得 1 个。
- **简易麻绳**：物品注册、中英文名称、模型与贴图已完成，可在创造模式原料栏找到。
- 已确定采用 **3 个植物纤维无序合成 1 个简易麻绳**，可使用背包的 2×2 合成栏；该配方当前尚未实现。
- **简易绷带尚未实现**，其材料、产量与效果待确定。它与上面的普通绷带是不同的设计对象。

### 薄荷与薄荷茶

- 野生薄荷自然生成、采集与耕地种植，包含四档生长外观和骨粉催熟。
- 满水炼药锅下放置燃烧的营火或岩浆块，投入两个薄荷，累计加热 400 游戏刻（正常速度约 20 秒），冲泡四瓶薄荷茶。失去热源时暂停，恢复热源后继续。
- 用玻璃瓶手动盛取；饮用恢复 2 点饥饿值，饱和系数为 0.3，饮后返还玻璃瓶。
- 获得薄荷解锁“医学之始”，首次喝下薄荷茶解锁“清凉一夏”。根进度使用单蛇缠杖图标。
- 薄荷与薄荷茶附有中英文悬停提示，说明种植、冲泡和饮用方式。

薄荷茶目前没有治疗或防暑效果。

## 接下来的开发

1. 完成并测试简易麻绳的无序合成配方。
2. 确定简易绷带的制作与使用规则，继续打通早期急救材料链。

以下为保留设想，尚未实现，也不代表已经确定完整规则：

- 出生赠送暂名《本草纲目》的游戏内玩法指南；发放、补领与阅读形式待讨论。
- 改善沙漠、寒冷群系的纤维获取途径；枯死灌木是候选来源之一。
- 双手持植物纤维长按 4 秒的手工捻绳方式；当前优先实现上述合成配方。
- 伤口感染、酒精绷带、发酵、蒸馏和草药研磨等后续系统。

搅拌继续保留为设计方案；漏斗投料、自动补水和自动装瓶暂缓。

## 开发环境

- Minecraft Java 1.21.4、Fabric Loader 0.19.5、Fabric API 0.119.4+1.21.4。
- Gradle Wrapper 9.7.1、Fabric Loom 1.18-SNAPSHOT，使用 Mojang mappings。
- **构建 Gradle 使用 JDK 25 或更高版本，开发游戏使用 JDK 21。** 本地使用 JDK 26 构建，编译目标为 Java 21。

用 IntelliJ IDEA 打开项目根目录并导入 Gradle。将 Gradle JVM 设为 JDK 25 或更高版本。`gradle.properties` 中的 `org.gradle.java.installations.paths` 是原开发机器的 JDK 21 路径；在另一台机器上，请改为自己的 JDK 21 安装目录。

Windows PowerShell 中，在项目根目录运行：

```powershell
.\gradlew.bat runClient
.\gradlew.bat build
```

构建产物为 `build/libs/project-medica-1.0.0.jar`；安装模组时使用这个文件，不使用 `-sources.jar`。游戏需要同时安装对应的 Fabric Loader 与 Fabric API。

按需运行独立服务端 GameTest：

```powershell
.\gradlew.bat runGameTest -PmedicaGameTests
```

测试世界位于 `build/run/gameTest`，测试代码不会进入发布 JAR。目前这组 GameTest 覆盖薄荷茶冲泡流程，不代表所有急救与材料链功能都有自动化测试。更多验证步骤见 [冲泡测试说明](docs/mint-tea-testing.md)。
