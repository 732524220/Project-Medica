# 薄荷茶自动冲泡测试

## 游戏内操作

1. 重新启动 IDEA 的 `runClient`，进入测试世界。
2. 放置岩浆块或点燃营火（普通营火、灵魂营火均可），在其正上方放置原版炼药锅，中间不隔方块。
3. 用水桶加满水，切换生存模式，手持至少 2 个薄荷右键锅。
4. 应只扣除 2 个薄荷，显示开始冲泡。空手右键可查看剩余加热时间。
5. 两种热源均在正常游戏速度下累计加热约 20 秒，出现泡好提示、声音与粒子。
6. 使用玻璃瓶可盛取 4 瓶薄荷茶，液面下降，最后恢复原版空锅。

这一步用原版水锅开始，不要用指令直接放置未泡好的茶锅；指令锅没有投入材料，不会自动冲泡。创造模式沿用不消耗材料的规则，数量测试请用生存模式。

## 暂停与保存

- 冲泡一半后用铲子熄灭营火，右键锅应显示已暂停，进度保持。
- 再点燃营火，应从原进度继续。
- 使用岩浆块时，移走岩浆块应暂停，放回后应继续；冲泡途中也可以在岩浆块与燃烧的营火之间切换，进度不重置。
- 无热源时向满水锅投入薄荷，应提示“下方没有热源，请放置篝火或岩浆块”，水与薄荷不消耗。熄灭的普通营火和灵魂营火均不能供热。
- 退出保存再进入世界，进度应保留。离线期间以及区块不再运行期间不会加热。
- 泡好后可以灭火，成品仍可装瓶。重复投入薄荷不会消耗材料或开始第二锅。
- 使用镐拆锅，返还一个原版空炼药锅，当前批次和茶水不保留。

## 开发自动测试

使用项目原有的 Gradle JVM 与 Java 21 游戏工具链运行：

```text
gradlew.bat runGameTest -PmedicaGameTests --offline --console=plain
```

仅显式启用 `medicaGameTests` 时加载独立测试源集，世界位于 `build/run/gameTest`，普通 `build` 和发布 JAR 不包含测试模组。无需开启客户端窗口。测试覆盖计时、暂停、真实 NBT 序列化与加载、装瓶数量、非法输入、副手、创造、背包满以及拆锅。
